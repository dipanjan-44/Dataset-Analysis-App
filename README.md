# Dataset-Analysis-Website
A Python website that analyzes uploaded CSV or Excel files and generates various visualizations. This code uses Streamlit for the web interface and pandas/matplotlib/seaborn for data analysis and visualization.
I've created a comprehensive data visualization web application using Python and Streamlit. This app allows you to upload CSV or Excel files and automatically generates a variety of visualizations and analyses.
Features of the App:
1. Data Summary

Basic statistics (rows, columns, missing values)
Data preview and data types
Missing values visualization
Summary statistics for all columns

2. Numeric Data Visualization

Histograms with density curves
Box plots to identify outliers
Q-Q plots to check for normal distribution
Correlation heatmap between numeric variables

3. Categorical Data Visualization

Bar charts for frequency analysis
Pie charts for proportion analysis
Value count tables

4. Time Series Analysis

Line charts for time-based trends
Distribution by day of week
Monthly/yearly patterns

5. Relationship Analysis

Scatter plots with regression lines
Box plots comparing numeric values across categories
Heat maps for categorical relationships
Violin plots showing distributions

6. Downloadable Reports

Export all analyses and visualizations as a ZIP file
